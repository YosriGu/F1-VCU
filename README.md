# fs-ev-vcu

Formula Student EV vehicle control unit: CAN specification, DBC files, generated code, firmware libraries, tests and CI.
Build system: **CMake + GNU GCC** (host GCC for unit tests, `arm-none-eabi-gcc` for Cortex-M7).



> Status: **scaffold.** It contains working, tested CAN tooling and two firmware libraries
