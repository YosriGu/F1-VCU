# References (link only; do not commit vendor documents)

- DTI HV-500/HV-550 user manuals, DTI CAN Communication Description.
- Orion BMS 2 documentation (orionbms.com): CAN, custom broadcast messages, OBD2.
- NXP S32K3 reference manual, S32K344 data sheet, S32K3 RTD documentation, FS26 documentation. Register names for FlexCAN dedicated message buffers, individual masks and bus-off recovery must be checked there.
- Formula Student Rules 2026 (FSG). Read T11.8, T11.9, EV2.2, EV4.11, EV5.8, EV6 line by line.
- Public team repositories used as precedent : Berkeley FEB CAN library, FSLART VCU firmware, UBC Formula Electric, Yale Bulldog Racing `bdr-can-ids`.
- VESC CAN protocol documentation (DTI's protocol lineage).
